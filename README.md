# File-Sync-Tool

Sync files between dirs

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/File-Sync-Tool.git
cd File-Sync-Tool
go build -o file-sync-tool .
```

## Usage

```bash
.file-sync-tool .
.file-sync-tool --path ./src
```
